
## TanStack Query Keys

`"classrom", classroomId, "chats"` - `/api/classrooms/<classroomId>/chats`

`"chat", classroomId, chatId` - `/api/classrooms/<classroomId>/chats/<chatId>`

`"chat", classroomId, chatId, "messages"` - `/api/classrooms/<classroomId>/chats/<chatId>/messages`

`"classroom", classroomId` - `/api/classrooms/<classroomId>/`
